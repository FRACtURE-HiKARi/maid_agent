# Maid Agent
Extension mod from mod [Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid/tree/1.20). 
Some implementation ideas inspired from [Maid Storage Manager](https://github.com/zxy19/maid_storage_manager)
Introduce more LLM callable functions and behaviors.

## New Functions
- JEI item / recipe search
- storage operations
